# TSPLIB datasets

These benchmark instances from [TSPLIB](https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/)
are used for TSP evaluation. The benchmark file contents are preserved as supplied
in this repository from the original benchmark source; this reorganization makes
no changes to their contents or formats.

Included datasets:

- bays29 (`bays29.tsp`)
- berlin52 (`berlin52.tsp`)
- ch150 (`ch150.tsp`)
- kroA100 (`kroA100.tsp`)
- rat195 (`rat195.tsp`)
- st70 (`st70.tsp`)
